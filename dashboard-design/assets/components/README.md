# Components

Ten closed components. Each one answers one question. Open `preview.html` in a browser to see them all with sample data.

## Index
| Component | Question it answers | Size |
|---|---|---|
| [KPI + line](01-kpi-line.md) | How much, and where is it going? | 376×128 |

| [Variance bars](04-variance.md) | What grew and what fell vs last year? | 1024×440 |
