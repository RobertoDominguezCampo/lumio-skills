# KPI + bar

**Question it answers:** Where does it come from?

## When to use it
A total that is driven by a few categories (revenue by bike type).

## When not to
More than 5 categories: use 06 Ranking.

## Anatomy
- Label + change pill top right
- Hero value
- 100% stacked bar, the biggest driver in accent, the rest neutral
- Legend row with %, the driver % in accent

## Size
376×128 (512×440 with horizontal bars when there is room). Only sizes from the layout grid.

## Style rules
- Follow the tokens and the quality bar in README.md.
- Title 19 px bold, hero 30 px bold, labels 13 px, axis 11 px. Tabular numbers.
- One accent highlight only. Red only for bad values, green only for on track.
- No empty space: if it doesn't fill the card, use the smaller size.
