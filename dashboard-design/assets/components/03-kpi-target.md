# KPI vs target

**Question it answers:** Will we make it?

## When to use it
A metric with an agreed target (utilization, sales YTD).

## When not to
There is no real target: don't invent one.

## Anatomy
- Label + status badge (red below target, green on track)
- Hero value + target + one line of why
- Progress track with the value in ink and a target tick in accent

## Size
376×128. Only sizes from the layout grid.

## Style rules
- Follow the tokens and the quality bar in README.md.
- Title 19 px bold, hero 30 px bold, labels 13 px, axis 11 px. Tabular numbers.
- One accent highlight only. Red only for bad values, green only for on track.
- No empty space: if it doesn't fill the card, use the smaller size.

## In Power BI
Power BI: card + bullet-style bar (stacked bar + target line) or KPI visual.
