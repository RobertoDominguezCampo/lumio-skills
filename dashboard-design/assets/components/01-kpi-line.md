# KPI + line

**Question it answers:** How much, and where is it going?

## When to use it
A headline metric that needs its recent direction (rides, revenue, turned away).

## When not to
The trend is flat or noisy and adds nothing: use a KPI with a status badge instead.

## Anatomy
- Label (metric + period)
- Hero value
- Change pill vs last year (accent if good, red if bad)
- Sparkline on the right: this period solid, last year dashed grey, dot on the last point, light area fill
- Tiny axis labels: start and now

## Size
376×128. Only sizes from the layout grid.

## Style rules
- Follow the tokens and the quality bar in README.md.
- Title 19 px bold, hero 30 px bold, labels 13 px, axis 11 px. Tabular numbers.
- One accent highlight only. Red only for bad values, green only for on track.
- No empty space: if it doesn't fill the card, use the smaller size.
